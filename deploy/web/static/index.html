    How it works
    

      

        

          This page is a Magic Wormhole client
          that runs entirely in your browser via WebAssembly. Encryption keys are
          negotiated client-side using SPAKE2 and all data is encrypted with NaCl
          SecretBox. The server never sees your files.
        

        

          Fully interoperable with all Magic Wormhole clients — send from your
          browser, receive on the command line, or vice versa.
